Первый запуск — настройка Firebase

Введите данные вашего Firebase проекта. Найти их можно в Firebase Console → Project Settings → Your apps → Web app → SDK snippet.

💡 Firebase config — не секрет: он всегда виден в JS на стороне клиента. Безопасность обеспечивается правилами Firestore. После подключения создайте правила: разрешите чтение/запись только авторизованным запросам или оставьте открытыми на время тестирования.
